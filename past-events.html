Adding a Past Event

To add a past event recap, create a markdown file in the _events folder:

  1. Name the file YYYY-MM-DD-event-name.md (e.g., 2025-09-15-fall-kickoff.md)
  2. Add event details in the front matter (title, date, location, photos)
  3. Write your event recap in the body using markdown
  4. Place event images in assets/images/events/
Example markdown file 
---
title: "Fall Kickoff Meeting"
event_date: 2025-09-15
time: "6:00 PM - 8:00 PM"
location: "McElhinney Hall, Room 100"
description: "Our first meeting of the fall semester."
image: "/assets/images/events/fall-kickoff.jpg"
photos:
  - image: "/assets/images/events/fall-kickoff-1.jpg"
    caption: "Members networking before the event"
  - image: "/assets/images/events/fall-kickoff-2.jpg"
    caption: "President giving the welcome address"
---
